# Диагностика по PNG и логу

| Симптом | Причина | Что сделать |
|---|---|---|
| Экран пустой, `-> пусто` в логе | неверный `root` или контент не успел отрисоваться | проверить селектор в DevTools; поднять `settle_ms` до 800–1500 |
| Видна служебная панель, рамка телефона, тень | не хватает `fix_css` | спрятать панель `display:none!important`, у рамки убрать `border`, `border-radius`, `box-shadow` |
| Экран обрезан по высоте окна | внутренний скролл | задать `scroll_container` и `min_height`; убедиться, что `html, body` и обёртки не ограничивают высоту (`height:auto!important; overflow:visible!important`) |
| Все маршруты дают один экран | роутер не реагирует на `location.hash` | попробовать `navigation = "url"` или `js` |
| Многие маршруты `-> дубликат` | несуществующие идентификаторы: все ведут на экран «не найдено» | взять реальные id из данных мокапа |
| Маршрут `-> /login` или `-> /welcome` | персона не авторизована для этого экрана | перенести маршрут в другую группу или поправить `setup` |
| Состояние сбрасывается между экранами | `navigation = "url"` перезагружает страницу | `setup_each_route = true` |
| Лишние подписи вроде «placeholder», артикулы в пустых картинках | текст скрыт не через цвет, а через `font-size:0`, `text-indent` или `clip` | добавить в `fix_css` правило `.selector{color:transparent!important}` для этих элементов |
| В Figma тексты переносятся не так, как в PNG | шрифт съёмки отличается от Figma | `dom2figma doctor`; поставить шрифт локально; проверить `force_font = true` |
| В Figma изображения пустые | внешние URL картинок не переносятся | предупредить пользователя; при необходимости заменить в мокапе на data URL |
| `ошибка: не удалось запустить Chrome` | Chrome не найден или не запускается | `chrome = "/путь"` в конфиге, переменная `CHROME`; в контейнере добавить `--no-sandbox` невозможно из конфига, запускать на хосте |
| `JS: ...` при `setup` | селектор не нашёл элемент | открыть мокап, проверить селектор; помнить, что панель может быть скрыта `fix_css` только после `setup` |

## Как читать лог capture

```
=== Гость ===
  /welcome  390x844                   снят
  /cart -> /welcome  390x844          редирект: гостю корзина недоступна
  /product/p99 -> дубликат /product/p98   одинаковое дерево, скорее всего «не найдено»
  /catalog  390x3577  (= Гость:/catalog)  совпадает с экраном другой группы
```

В JSON экраны с `sameAs` остаются, плагин пропускает их при включённом флажке дедупликации.
