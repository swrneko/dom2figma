# dom2figma: мокап → Figma

CLI `dom2figma` снимает отрисованный DOM в headless Chrome и пишет JSON, а Figma-плагин из этого JSON строит фреймы, текстовые слои и векторы. Твоя задача как агента: разобраться в устройстве мокапа, написать конфиг, снять экраны, проверить результат по PNG и выдать пользователю инструкцию по импорту.

## Предусловия

Проверь, что бинарник установлен и окружение готово:

```bash
dom2figma --version || cargo install --git https://github.com/swrneko/dom2figma
dom2figma doctor
```

`doctor` находит Chrome и проверяет шрифт. Если шрифт не найден, скажи пользователю, как поставить (Linux: TTF в `~/.local/share/fonts/` и `fc-cache -f`; macOS: Font Book). Без совпадающего шрифта переносы строк в Figma разойдутся, съёмку всё равно можно продолжать.

## Процедура

### 1. Разведка мокапа

Определи три вещи, не спрашивая пользователя, если это можно выяснить из кода или в браузере:

- **Корень экрана.** Для сайта это `body`. Для стенда с рамкой телефона или служебной панелью найди селектор самого экрана (пример: `.device`). Признаки: фиксированная ширина 360–430 px, `overflow: hidden`, соседняя панель с переключателями.
- **Навигация.** Адрес меняется как `#/route` → `hash`. Меняется путь → `url`. Не меняется → `js` (маршруты становятся JS-выражениями с кликами).
- **Состояния.** Персоны, роли, авторизация, темы. Каждое — отдельная группа с `setup`-скриптом.

Список маршрутов ищи в коде роутера (`path:`, `route:`, `createBrowserRouter`, `<Route>`), в sitemap или в навигации. Для параметризованных маршрутов подставь реальные идентификаторы из данных мокапа.

Полезно открыть мокап в браузере через chrome-devtools MCP и посмотреть DOM панели и экрана, чтобы селекторы для `setup` были точными.

### 2. Конфиг

В каталоге мокапа: `dom2figma init`, затем заполни `dom2figma.toml`. Поля и примеры смотри в [references/config.md](references/config.md). Правила:

- `fix_css` обязателен, если есть служебная обвязка: спрячь панели, убери рамку и тень устройства, дай `html, body` расти по высоте.
- Если внутри экрана свой скролл, задай `scroll_container` и `min_height`, иначе экраны обрежутся по высоте окна.
- Начинай с 3–5 ключевых маршрутов, полный список добавляй после первой удачной съёмки.

### 3. Съёмка и проверка

```bash
dom2figma capture --route "/" --no-png       # быстрый пробный снимок
dom2figma capture                              # полный прогон
```

Обязательно посмотри несколько PNG из `out/png/<группа>/` инструментом Read и сверь с мокапом. Диагностика типовых дефектов в [references/troubleshooting.md](references/troubleshooting.md). Повторяй, пока экраны не будут выглядеть как в браузере. В логе `capture` обращай внимание на `-> дубликат` и `->` редиректы: это подсказки о неверных идентификаторах и недоступных для персоны маршрутах.

### 4. Передача пользователю

```bash
dom2figma plugin                               # figma-plugin/ для Figma Desktop
dom2figma serve & dom2figma scripter --out scripter.js   # вариант для браузерной Figma
```

В ответе пользователю укажи: сколько экранов снято и сколько уникальных, где JSON и PNG, и короткую инструкцию импорта под его случай. Figma Desktop и figma-linux: Plugins → Development → Import plugin from manifest → `figma-plugin/manifest.json`, запустить плагин, выбрать JSON. Браузер: `dom2figma serve` оставить работать, содержимое `scripter.js` вставить в плагин Scripter и нажать Run. На бесплатном плане Figma лимит 3 страницы на файл, поэтому плагин по умолчанию кладёт группы секциями на одну страницу.

## Ограничения, о которых нужно предупреждать

- Слои позиционируются абсолютно, auto layout не строится.
- Растровые картинки только как data URL; внешние изображения останутся прямоугольниками с заливкой.
- Линейные градиенты и простые тени переносятся, радиальные градиенты, фильтры и трансформы нет.
- Состояния по действию (модалки, ховеры) снимаются только через `setup` или режим `js`.

## Чего не делать

- Не снимать все 100 маршрутов до проверки первого экрана.
- Не менять `assets/serialize.js` или плагин под конкретный мокап: специфика проекта живёт в `dom2figma.toml`.
- Не выдавать результат, не посмотрев PNG.
